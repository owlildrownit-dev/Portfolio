# Red Light Detection

An educational application described in the [technical report](../samples/red-light-report.md). The portfolio case focuses on the documentation work: writing, formatting, editing, and correction.

## System described in the report

The application accepts photographs and video files through a local interface. The report describes a FastAPI backend, vehicle detection with YOLOv8n and ONNX Runtime, OpenCV image processing, a custom IoU tracker, SQLite history storage, and PDF and spreadsheet export.

## Documentation available

The report contains requirements and acceptance criteria, architecture and workflow diagrams, algorithm descriptions, storage and API summaries, and installation and usage appendices.

[Read the documentation case](../samples/red-light-report.md)

## Evidence boundary

This overview summarizes the supplied report. It does not verify the software against its repository. Conflicting descriptions of photo-analysis status, fallback modes, and performance are recorded in the editorial review included with the portfolio source package.
